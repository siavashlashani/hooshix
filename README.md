# هوشیکس (Hooshix) — لندینگ راهکارهای هوش مصنوعی برای کسب‌وکار

سایت تک‌صفحه‌ای، فارسی و راست‌چین (RTL) با تم **سفید و بنفش** برای معرفی خدمات هوش مصنوعی برند «هوشیکس»: مشاوره، ساخت سیستم‌های AI، اتوماسیون و طراحی سایت هوشمند.

## ✅ بخش‌های پیاده‌سازی‌شده (بر اساس بریف `docs/brief.md`)

| # | بخش | توضیح |
|---|-----|-------|
| ۱ | هدر | لوگو + منوبار + دکمه «ثبت‌نام / ورود» (اسکرول‌چسبان، منوی همبرگری در موبایل) |
| ۲ | هیرو | تیتر برند + دو بنر کنار هم («کسب‌وکار دارم» / «می‌خوام کسب‌وکار راه بندازم») با تصویر، متن و دکمه «مشاوره بگیر» — متن‌ها دقیقاً از بریف |
| ۳ | نوار لوگوی ابزارهای AI | ChatGPT، Gemini، Claude، n8n، Zapier، Perplexity، Copilot، Hugging Face، Llama، Make، ElevenLabs، Notion AI — اسکرول افقی خودکار بی‌نهایت (با هاور متوقف می‌شود) |
| ۴ | نمایش نتیجه | ۴ فریم زیر هم با عنوان کوتاه: **چت‌بات هوشمند** (مکالمه زنده شبیه‌سازی‌شده) → **ایجنت خودکار** (اجرای مرحله‌ای تسک + لاگ) → **اتوماسیون کسب‌وکار** (جریان Instagram → AI → Sheets → Telegram) → **تولید محتوا و کاراکتر** (کاراکتر تولیدشده + کپشن تایپ‌شونده) |
| ۵ | مشکل و راه‌حل | ۴ کارت سوال → پاسخ (اتوماسیون / AI Agent / مشاوره / سایت + AI) |
| ۶ | کارت‌های خدمات | ۴ دسته با زیرمجموعه‌های دقیق بریف (مشاوره و استراتژی AI، ساخت سیستم‌های AI، اتوماسیون با n8n، ساخت و توسعه سایت) |
| ۷ | نحوه کارکرد | مشاوره ← انتخاب ← اجرا |
| ۸ | CTA میانی | دو دکمه مجزا (مشاوره / شروع) |
| ۹ | FAQ | ۶ سوال دقیقاً از بریف، آکاردئونی |
| ۱۰ | فوتر | لوگو + توضیح برند، دسترسی سریع، راه‌های ارتباطی، شبکه‌های اجتماعی (اینستاگرام/تلگرام/ایکس/لینکدین)، دکمه مشاوره، کپی‌رایت ۲۰۲۶ |

### فرم چندمرحله‌ای هوشمند (Modal)
- **هر** دکمه «مشاوره بگیر» در سایت (هیرو، خدمات، CTA میانی، فوتر، منوی موبایل) فرم را به‌صورت **پنجره شناور** باز می‌کند؛ کاربر از صفحه خارج نمی‌شود و بعد از بستن به همان نقطه برمی‌گردد.
- **مرحله ۱:** وضعیت کسب‌وکار (تک‌انتخابی) — بنرهای هیرو گزینه را از قبل انتخاب می‌کنند.
- **مرحله ۲ (شرطی):**
  - *کسب‌وکار دارم:* نوع کسب‌وکار (فروشگاه/خدماتی/تولیدی/دیگر + فیلد متنی)، خدمت مورد نیاز (چند‌انتخابی: چت‌بات/ایجنت/اتوماسیون/تولید محتوا و کاراکتر/وبسایت)، بزرگ‌ترین چالش (اختیاری)
  - *می‌خوام راه بندازم:* نوع کسب‌وکار (متنی)، خدمت (چند‌انتخابی: وبسایت/تولید محتوا و کاراکتر/چت‌بات/اتوماسیون)، مرحله (فقط ایده / برنامه دارم / تازه شروع کردم)
- **مرحله ۳:** نام و نام‌خانوادگی، شماره تماس (اجباری، اعتبارسنجی موبایل ایران با ارقام فارسی/انگلیسی)، بهترین زمان تماس (صبح/ظهر/عصر — اختیاری)
- ارسال به جدول `consultations` از طریق RESTful Table API + پیام موفقیت.

## 🗂 ساختار فایل‌ها
```
index.html          صفحه اصلی (تمام ۱۰ بخش + مودال فرم)
css/style.css       استایل کامل، تم بنفش/سفید، ریسپانسیو، انیمیشن‌ها
js/main.js          منو، مارکی، انیمیشن فریم‌ها، FAQ، مودال چندمرحله‌ای و ارسال فرم
images/             hero-business.png, hero-startup.png, character-sample.png
docs/brief.md       بریف اصلی پروژه
```

## 🔗 مسیرهای کاربردی
- `index.html` — صفحه اصلی؛ انکرها: `#hero-section`, `#tools-section`, `#results-section`, `#problems-section`, `#services-section`, `#process-section`, `#cta-section`, `#faq-section`, `#footer`
- `POST tables/consultations` — ثبت درخواست مشاوره
- `GET tables/consultations?page=1&limit=100` — مشاهده درخواست‌ها

## 🗄 مدل داده — جدول `consultations`
| فیلد | نوع | توضیح |
|------|-----|-------|
| id | text | شناسه |
| business_status | text | `have_business` / `start_business` |
| business_type | text | نوع کسب‌وکار |
| services | array | خدمات انتخاب‌شده |
| challenge | text | چالش فعلی (اختیاری) |
| stage | text | `idea` / `planned` / `started` |
| full_name | text | نام و نام‌خانوادگی |
| phone | text | شماره موبایل نرمال‌شده (09xxxxxxxxx) |
| call_time | text | `morning` / `noon` / `evening` |
| source | text | دکمه‌ای که فرم از آن باز شده (برای تحلیل تبدیل) |

## 🚧 پیاده‌سازی‌نشده / محدودیت‌ها
- **ثبت‌نام / ورود:** فقط دکمه نمایشی است (یک سایت استاتیک نمی‌تواند احراز هویت امن سمت سرور داشته باشد).
- تصویر نمونه «محتوای تولیدشده» (گرید پست‌های اینستاگرام) به‌دلیل پایان اعتبار تولید تصویر ساخته نشد؛ فریم ۴ فعلاً از کاراکتر تولیدشده + کپشن تایپ‌شونده استفاده می‌کند.
- شماره تماس، ایمیل و لینک شبکه‌های اجتماعی در فوتر **نمونه** هستند و باید با اطلاعات واقعی جایگزین شوند.
- صفحات جداگانه‌ی هر خدمت (مثلاً توضیح n8n) هنوز ساخته نشده‌اند.

## 💡 قدم‌های بعدی پیشنهادی
1. جایگزینی اطلاعات تماس و لینک‌های اجتماعی واقعی در فوتر.
2. اضافه‌کردن تصویر واقعی نمونه محتوا به فریم ۴ (`images/content-sample.png`).
3. ساخت صفحه ادمین ساده برای مشاهده درخواست‌های `consultations`.
4. صفحات اختصاصی هر خدمت + بخش «درباره من».
5. اتصال فرم به نوتیفیکیشن تلگرام/ایمیل (از طریق وب‌هوک n8n بدون کلید).
